D4EM0JP0Principe de fonctionnement : Antidémarrage
IMPERATIF : Lors du retour en garantie d’un calculateur moteur ou d’un BSI, il est obligatoire d’y adjoindre le code d’accès client.
Les éléments participant à l’antidémarrage du véhicule doivent être appairés.
La procédure d’appairage à l’aide du code unique est réalisable en après-vente.
Organes concernés Codes utilisés pour l’appairage
BSI Code d’accès client
Calculateur moteur Code d’accès client
clés Identifiants des clés, code d’accès client
1. Apprentissage des clés
L’identifiant de la clé doit être mémorisé dans le BSI pour permettre le démarrage du véhicule . Le BSI peut mémoriser 5 clés au maximum.
Pour mémoriser une nouvelle clé dans le BSI, il est indispensable de réapprendre toutes les clés.
L’identifiant du transpondeur d’une clé perdue ou volée est désactivé de la mémoire du BSI lors du réapprentissage des clés restant en possession du client.
2. Programmation du code d’accès client
Le code d’accès client est programmé à l’aide de l’outil de diagnostic.
3. Remplacement du BSI
Lors du remplacement du BSI, il faut effectuer les opérations suivantes :
  • Programmer en mémoire le code d’accès client
  • Réapprendre toutes les clés
IMPERATIF : L’opérateur a 3 tentatives pour rentrer le code d’accès client dans la mémoire du BSI, ensuite, le processus d’apprentissage est neutralisé pendant 1 minute.
NOTA : Le code d’accès client ne peut pas être lu dans le BSI.
4. Remplacement du calculateur moteur
Lors du remplacement du calculateur moteur, il faut effectuer les opérations suivantes :
  • Programmer le code d’accès client dans le calculateur moteur
  • Le calculateur moteur et le BSI doivent être appariés
Le contrôle d’appairage est réalisé à la demande de l’utilisateur.
IMPERATIF : La troisième tentative de programmation du code d’accès client est définitive.
L’appairage du calculateur moteur et du BSI se réalise avec le +APC, il faut donc au moins une clé reconnue par le BSI.
NOTA : Après la programmation du BSI ou du calculateur moteur, le contrôle d’appairage est destiné à figer les codes d’accès.
