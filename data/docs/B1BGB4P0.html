B1BGB4P0Appariement : Coussinets de palier
NOTA : Le carter-cylindres et le vilebrequin comportent des repères permettant l’appariement des coussinets de palier .
1. Moteur avec repérages
1.1. Identification
Figure : b1cp0ncd
Les classes des coussinets de palier de vilebrequin sont reportées sur le bloc moteur en " a" et sur le vilebrequin (côté distribution) en "b".
"c" Code à barres : Utilisé en usine.
"d" Caractères alphanumériques : Utilisé en "après-vente".
Le premier caractère correspond au palier N° 1, le deuxième au palier N° 2, ainsi de suite.
NOTA : Les paliers de vilebrequin sont repérés de 1 à 5, n°1 côté volant moteur.
1.2. Demi-coussinets supérieurs (rainurés)
NOTA : Il existe qu’une seule classe pour les demi-coussinets de palier de vilebrequin supérieurs rainurés.
- Cote nominale Repère couleur
Demi-coussinets supérieurs 1,859 ± 0,003 mm jaune
1.3. Demi-coussinets inférieur (lisse)
Figure : b1cp0ndd
Exemple :
  • Caractères relevés sur le vilebrequin : A7H6D
  • Caractères relevés sur le carter-cylindres : EPTG6
Pour le palier N° 1 (AE), le demi-coussinet inférieur à monter est de classe "C".
Pour le palier N° 2 (7P), le demi-coussinet inférieur à monter est de classe "D".
NOTA : Procéder de la même manière pour les 3 autres ensembles.

classe Cote nominale Repère couleur
classe "A" 1,846 ± 0,003 mm Bleu
classe "B" 1,853 ± 0,003 mm Noir

NOTA : En cas de défaillance des moyens de mesure, monter des demi-coussinets inférieurs de classe "A" (Couleur bleue) ; Cette pratique doit rester exceptionnelle, car le moteur peut s’avérer bruyant.
2. Moteur sans repérages
En présence d’un carter-cylindres ou d’un vilebrequin sans repères d’identification, utiliser une jauge plastique " PLASTIGAGE " type PG-1.
Nettoyer :
  • Le vilebrequin
  • Les chapeaux de paliers
  • Les demi-coussinets
ATTENTION : (respecter la position des demi-coussinets lisses et rainurés).
Poser :
  • Les demi-coussinets supérieurs (couleur jaune) sur les paliers côté carter-cylindres
  • Le vilebrequin
  • Les demi-coussinets de classe "A" (couleur bleue) sur les paliers côté carter-chapeaux de paliers
Figure : b1bpsjqd
Couper 5 morceaux de jauge plastique à la largeur des demi-coussinets.
Figure : b1bpsjrd
ATTENTION : Durant cette opération, le vilebrequin ne doit pas tourner.
Poser :
  • Les fils plastique sur chacune des portées du vilebrequin (La flèche indique le fil )
  • Le carter chapeaux de paliers
Reposer les vis du carter-chapeaux de paliers vilebrequin ; Préserrage : 2 ± 0,2 m.daN puis serrage angulaire 72 ± 5° (Serrage en escargot, vis par vis).
Figure : b1bpsjsd
Desserrer et déposer les vis du carter-chapeaux de palier vilebrequin .
Déposer le carter chapeaux de paliers.
Comparer chaque largeur (en mm) du fil plastique aplati à son point le plus large avec les graduations figurant sur les enveloppes papier.
La valeur lue indique le jeu de fonctionnement.
NOTA : La mesure peut s’effectuer sur le vilebrequin ou le demi-coussinet selon l’adhérence des portées.
Choisir la classe des coussinets de palier pour obtenir un jeu de fonctionnement de 0,01 mm à 0,036 mm.
Contrôler les jeux de la ligne d’arbre ; À l’aide de la jauge plastique " PLASTIGAGE ".
Nettoyer les traces de jauges plastique et huiler le vilebrequin.
