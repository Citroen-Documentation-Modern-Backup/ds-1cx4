1. Préambule
La communication entre les différents calculateurs du véhicule est réalisée sur les 4 réseaux multiplexés suivants :
  • Réseau CAN
  • Réseau VAN CARROSSERIE 1
  • Réseau VAN CARROSSERIE 2
  • Réseau VAN Confort
Le multiplexage consiste à véhiculer les données suivantes, sur un réseau bifilaire, sous forme numérique :
  • Commandes de fonctionnement
  • Informations d’états
  • Données de capteurs
Le BSI est le centre du réseau de communication.
Le BSI est une interface entre les réseaux VAN et CAN.
Le BSI est le calculateur assurant la liaison avec l’outil de diagnostic.
Le BSI gère également une stratégie de lestage et de délestage électrique.
Afin d’économiser l’énergie électrique de la batterie, le réseau électrique peut fonctionner selon les deux modes suivants :
  • Mode nominal
  • Mode économie, une partie des fonctions électriques est désactivée
Le BSI gère le passage du mode nominal au mode économie.
Les calculateurs peuvent être mis en veille pour diminuer la consommation électrique lorsque le moteur est non tournant.
Le BSI gère la mise en veille et le réveil des calculateurs.
