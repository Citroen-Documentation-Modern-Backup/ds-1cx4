B3FG4WP0Dépose - repose : Calculateur ABS
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Déposer :
  • Le cache batterie
  • Le cache boîtier calculateurs (BSM)
BSM : (boîtier de servitude moteur).
Déconnecter le câble négatif et le câble positif de la batterie.
Figure : b1bp26ec
Déposer vis (2).
Déconnecter les connecteurs (1).
Déposer :
  • Le bloc calculateurs ( 6)
  • Le faisceau (4)
  • La vis (3)
Écarter les 3 clips "a".
Écarter le BSM ( 5) du bac (7).
Figure : b1hp17tc
Déposer :
  • Les vis (8)
  • Le bac (7)
Figure : b3gp02wd
Déconnecter le connecteur (9).
Déposer :
  • Les écrous (12)
  • Les 2 vis (11) (voir nota)
  • Le calculateur ABS
Remplacer le calculateur ABS (si nécessaire).
NOTA : Côté moteur électrique, ne pas désolidariser le calculateur ABS du bloc hydraulique, puis l’écarter de la patte support.
ATTENTION : Ne pas tordre les tubes hydrauliques.
2. Repose
Effectuer la suite des opérations dans le sens inverse des opérations de dépose.
IMPERATIF : Remplacer systématiquement les vis (11).
Reposer et serrer les 2 vis (11).
Serrer les vis (11) à 0,55 ± 0,05 m.daN.
Reposer les écrous (12).
Serrer les écrous (12) à 0,8 ± 0,1 m.daN.
Reconnecter le connecteur (9).
Reposer :
  • Le bac ( 7)
  • Les vis (8)
  • Le BSM (5)
  • La vis (3)
  • Le bloc calculateurs (6)
  • La vis (2)
Reconnecter le connecteur (1).
Connecter le câble négatif et le câble positif de la batterie.
Reposer :
  • Le cache boîtier calculateurs (BSM)
  • Le cache batterie
Effectuer une lecture des codes défauts.
