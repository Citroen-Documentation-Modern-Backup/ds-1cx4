DEPUIS OPR 8879
1. Lecture des défauts
Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic :
  • Un ou plusieurs haut-parleurs défaillants
  • Défaut de réception de la radio
  • Défaut de lecture des CD audio (unité centrale)
  • Défaut de lecture des CD de données (unité centrale)
  • Défaut de lecture des CD audio et des CD de données (unité centrale)
  • Module GSM de l’antenne trifonctions défaillant ou débranché (non utilisé)
  • Module GPS de l’antenne trifonctions défaillant ou débranché (non utilisé)
  • Liaison I²C défaillante (défaut de communication entre l’unité centrale et l’unité annexe)
  • Liaison USB défaillante (défaut de communication entre unité centrale, l’unité annexe et le port USB)

3. Test actionneurs
Il est possible d’effectuer les tests actionneurs suivants À l’aide de l’outil de diagnostic :
  • Recherche montante des fréquences
  • Bip dans le haut-parleur avant gauche
  • Bip dans le haut-parleur avant droit
  • Bip dans le haut-parleur arrière gauche
  • Bip dans le haut-parleur arrière droit
4. Réinitialisation de l’AutoPc
Figure : d5ap01fc
Légende :
  • " a" : Bouton "RESET 2"
  • "b" : Bouton "RESET 1"
4.1. Réinitialisation logiciel
ATTENTION : Avant d’effectuer une réinitialisation usine, il est nécessaire de faire une sauvegarde des données et réglages personnels du client sur une carte CompactFlash.
Si l’AutoPC ne répond plus aux commandes, il faut effectuer une réinitialisation logiciel afin de remettre le système en état opérationnel.
Les signes indiquant un fonctionnement anormal peuvent être l’apparition d’un écran noir vierge ou l’affichage du message du type "Veuillez patienter..." pendant une durée excessive.
Il faut toujours essayer la procédure de réinitialisation logiciel en premier.
Action à effectuer Remarques
Appuyer sur le bouton "b" À l’aide d’une pointe fine (exemple : trombone ouvert) Les données en cours de saisie ne sont pas enregistrées
4.2. Réinitialisation matériel
Si une réinitialisation logiciel ne permet pas de remettre le système en état opérationnel, essayer une réinitialisation matériel.
Action à effectuer Remarques
Sauvegarder, si possible, les données mémorisées dans l’AutoPC sur une carte CompactFlash Après une réinitialisation matériel, le système sera réinitialisé aux paramètres programmés en usine
Appuyer simultanément sur les bouton " a" et "b" À l’aide d’une pointe fine Liste des éléments perdus après l’opération : Carnet d’adresses, Mémos vocaux, Données et réglages personnels, TMC (Traffic Message Channel), Téléphone, Messages vocaux, Navigation
Attendre 2 secondes
Relâcher le bouton "b", puis le bouton "a"
ATTENTION : Si aucune sauvegarde n’est effectuée, les données présentes dans la RAM seront perdues.
Après une réinitialisation matériel, effectuer les opérations suivantes :
  • Réinstallation à l’aide du CD-ROM de logiciels ou restauration à l’aide d’une carte CompactFlash (voir opération correspondante)
  • Synchronisation des 2 unités de commande
4.3. Synchronisation des 2 unités de commande
L’unité centrale et l’unité annexe communiquent entre elles via les réseaux I²C et USB.
Les 2 unités de commande utilisent chacune une horloge qui leur permet de reconnaître les trames.
Si les 2 horloges ne sont pas synchronisées, une trame émise par une unité peut être considérée comme invalide par l’unité destinataire de cette trame.
Des problèmes de communication peuvent alors apparaître et perturber les fonctions suivantes :
  • Réception radio RDS
  • Lecture de CD
  • Navigation
  • Téléphone
  • TMC (Traffic Message Channel)
  • Amplificateur de puissance
Après une procédure d’installation ou de restauration du système, les 2 unités de commande doivent être synchronisées.
Figure : d5bp008c
" c" : Orifice du bouton de synchronisation.
Effectuer les opérations suivantes :
  • Enlever la garniture de l’unité annexe
  • Effectuer une pression sur le bouton de synchronisation situé dans l’orifice " c" À l’aide d’une pointe fine
  • Effectuer immédiatement une réinitialisation logiciel de l’AutoPC (pression sur le bouton "RESET 1")
  • Reposer la garniture de l’unité annexe
5. Débranchement ou remplacement de la batterie
En cas de débranchement de la batterie, un accumulateur de sécurité permet de maintenir l’alimentation et les données du système AutoPC pendant 3 jours.
L’accumulateur de sécurité est également utilisé dans les cas suivants :
  • Décharge de la batterie du véhicule
  • Dépose des fusibles F20 ou F24
  • Retour au mode "Park" (déplacement du fusible SH)
Si le temps d’autonomie de l’accumulateur de sécurité est dépassé, les données suivantes sont perdues :
  • Carnet d’adresses
  • Mémos vocaux
  • Données et réglages personnels (réglages de l’AutoPC, apprentissages personnalisés de la voix du client)
  • Applications (messages, navigation, TMC, téléphone)
IMPERATIF : Avant de débrancher la batterie du véhicule pour plus de 3 jours, il est nécessaire d’effectuer une sauvegarde sur une carte CompactFlash.
6. Débranchement des unités de commande
Le débranchement d’une ou plusieurs unités de commande peut avoir les conséquences suivantes
Action Effet sur la sauvegarde des informations
Débranchement des liaisons entre les 2 unités de commande Aucune information n’est perdue
Débranchement de l’unité annexe (batterie du véhicule branchée)
Débranchement de l’unité centrale Perte de toutes les informations présentes dans la RAM de l’AutoPC
Débranchement de l’unité annexe (batterie du véhicule débranchée)
IMPERATIF : Avant de débrancher une unité de commande, il est nécessaire d’effectuer une sauvegarde sur une carte CompactFlash.
7. Sauvegarde et restauration des informations
Les options de sauvegarde et de restauration permettent de manipuler les données et les paramètres du système À l’aide d’une carte CompactFlash.
NOTA : Il est recommandé d’utiliser une carte CompactFlash d’une taille de 32Mo.
Figure : d5ap01jc
(1) Carte CompactFlash.
7.1. Sauvegarde des informations
La sauvegarde des informations sur la carte CompactFlash exporte et protège toutes les données stockées dans la RAM de l’AutoPC.
ATTENTION : Pendant l’opération de sauvegarde, il est impossible d’utiliser d’autres programmes de l’AutoPC avant que la sauvegarde ne soit terminée.
Effectuer les opérations suivantes
Étape Action à effectuer
1 Sélectionner "Configuration" dans le menu de démarrage
Appuyer sur "ENTRÉE"
2 Sélectionner "Sauvegarde/Restauration"
Appuyer sur "ENTRÉE"
3 Sélectionner "Sauvegarde"
Appuyer sur "ENTRÉE"
4 Appuyer sur "ENTRÉE" (début de l’opération de sauvegarde)
Suivre les instructions à l’écran multifonction
5 Insérer une carte CompactFlash dans l’AutoPc, étiquette dirigée vers la gauche
6 Sélectionner "OK"
Appuyer sur "ENTRÉE" (sauvegarde des informations)
Sinon, sélectionner "Supprimer" pour abandonner l’opération
NOTA : Si la carte CompactFlash ne dispose plus d’assez d’espace mémoire disponible, choisir "Formater" dans les options du menu de configuration . Toutes les données présentes sur la carte CompactFlash seront définitivement supprimées.
7.2. Restauration des informations
La restauration des informations à partir de la carte CompactFlash remplace toutes les données stockées dans l’AutoPC.
Effectuer les opérations suivantes
Étape Action à effectuer
1 Sélectionner "Configuration" dans le menu de démarrage
Appuyer sur "ENTRÉE"
2 Sélectionner "Sauvegarde/Restauration"
Appuyer sur "ENTRÉE"
3 Sélectionner "Restauration"
Appuyer sur "ENTRÉE"
4 Appuyer sur "ENTRÉE" (début de l’opération de restauration)
5 Insérer une carte CompactFlash dans l’AutoPc, étiquette dirigée vers la gauche
6 Sélectionner "OK"
Appuyer sur "ENTRÉE" (restauration des informations)
Sinon, sélectionner "Supprimer" pour abandonner l’opération
