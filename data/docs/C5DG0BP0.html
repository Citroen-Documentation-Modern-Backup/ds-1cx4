1. Dépose
Déposer (voir opération correspondante) :
  • Le pare-boue avant (partie avant)
  • Le pare-chocs avant

Déconnecter les connecteurs (1), (3) et (7).
Désaccoupler le tuyau lave-vitre ( 2).
Décliqueter les tuyaux de lave-projecteurs ( 8) (suivant option).
Déposer les vis ( 5) et (6).
Figure : c4ap142c
Chasser l’axe central, puis déposer le pion ( 10).
Déposer :
  • La tubulure de remplissage ( 9)
  • Le réservoir de lave-vitre (4)
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
