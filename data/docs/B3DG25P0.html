B3DG25P0Dépose - repose : Essieu arrière
DEPUIS OPR 8631
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Dépose
Lever et caler le véhicule, roues arrière pendantes.
IMPERATIF : Se reporter aux directives de l’opération "mise hors pression des circuits de suspension".
Déposer la ligne d’échappement .
Figure : b3dp083c
Déconnecter le connecteur (1).
Figure : b3fp7dhc
Déposer :
  • La vis (2)
  • Le capteur de roue
Dégrafer le faisceau du capteur de roue de l’essieu arrière.
Écarter le faisceau du capteur de roue de l’essieu arrière.
1.1. Véhicules sans suspension hydractive
Figure : b3dp084c
Désaccoupler le tube (4).
Obturer les orifices des organes hydrauliques à l’aide de bouchons.
1.2. Véhicules avec suspension hydractive
Figure : b3dp085c
Déconnecter le connecteur (5).
Désaccoupler :
  • Le tube (6)
  • Le tuyau (7)
Obturer les orifices des organes hydrauliques à l’aide de bouchons.
1.3. Véhicules tous types
Figure : b3dp0b9d
Désaccoupler les flexibles de frein (8).
Figure : b3dp087c
Désaccoupler le tube de suspension en " a".
Obturer les orifices .
Maintenir l’essieu arrière à l’aide d’un outil de levage.
Figure : b3dp088d
Déposer :
  • Les vis (9)
  • Les vis (10)
Dégager l’essieu arrière (vers le bas).
2. Repose
Présenter l’essieu arrière sous la caisse dans la même position que pour la dépose.
Reposer :
  • Les vis (9)
  • Les vis (10)
Serrer les vis (9) à 11,5 ± 1,1 m.daN.
Serrer les vis (10) à 11,1 ± 1,1 m.daN.
Accoupler :
  • Le tube de retour suspension en " a"
  • Les flexibles de frein (8) Serrage à 1,5 ± 0,3 m.daN
2.1. Véhicules sans suspension hydractive
Accoupler le tube (4) Serrage à 1,6 ± 0,3 m.daN.
2.2. Véhicules avec suspension hydractive
Accoupler :
  • Le tube (6) Serrage à 1,6 ± 0,3 m.daN
  • Le tuyau (7)
Reconnecter le connecteur (5).
2.3. Véhicules tous types
Reposer les capteurs de roue ( 3).
NOTA : Enduire le filetage de la vis ( 2) de produit (LOCTITE FRENETANCH).
Serrer la vis (2) à 0,8 ± 0,1 m.daN.
Agrafer les faisceaux des capteurs de roue sur l’essieu arrière.
Reconnecter le connecteur (1).
Reposer la ligne d’échappement.
Purger le circuit de freinage (voir opération correspondante).
Purger le circuit de suspension (voir opération correspondante).
