DEPUIS OPR 8631
1. Préambule
Le véhicule peut être équipé des éléments suivants :
  • Autoradio  (avec lecteur cassette, avec lecteur de disques compacts ou avec radiotéléphone)
  • Changeur de disques compacts
  • Amplificateur de puissance
  • Commande de système audio intégrée au module de commutation sous volant de direction
On distingue les 3 types d’autoradio suivants.
Appellation Description
RB2 Récepteur radio équipé d’un lecteur de cassette mécanique
RD2 Récepteur radio équipé d’un lecteur de disques compacts
RT2 Récepteur radio équipé d’un radiotéléphone GSM
Les autoradios ont en commun les caractéristiques suivantes :
  • Affichage déporté vers l’écran multifonction pour la radio et la lecture de supports musicaux
  • Commande de système audio intégrée au module de commutation sous volant de direction
  • Compatibilité avec un changeur de disques compacts
NOTA : L’autoradio RT2 possède également un afficheur intégré pour réaliser l’affichage de la fonction radiotéléphone.
IMPERATIF : Ne pas monter de changeur CD du commerce. Le seul changeur CD compatible avec les autoradios est le changeur 6 disques disponibles en accessoirie CITROËN.

3.6. Commandes du système audio
3.6.1. Module de commutation sous volant de direction
Le module de commutation sous volant de direction retransmet au BSI les actions de l’utilisateur via le réseau multiplexé VAN CAR 1.
Figure : d4ap01jd
Le module de commutation sous volant de direction est un boîtier monobloc regroupant.
Légende :
  • (20) : Le commutateur d’éclairage
  • (21) : Le support combinateur
  • (22) : Le contact tournant
  • (23) : Le commutateur d’essuyage
  • (24) : La commande de système audio
  • (25) : Le commutateur de régulation de vitesse  (selon version)
3.6.2. Commandes du système audio
(24) : Les commandes du système audio sont intégrées au module de commutation sous volant de direction selon le schéma suivant.
Figure : d4ap01kd
Légende :
  • "A" : Vue arrière
  • "B" : Vue avant
  • ("a") : Molette de changement des présélections radio
  • ("b") : Bouton d’avance rapide/bouton de recherche montante (*)
  • ("c") : Bouton de retour rapide/bouton de recherche descendante (*)
  • ("d") : Bouton de réglage du volume "+"
  • ("e") : Bouton de changement de source audio / de passage en mode téléphone "-"
  • ("f") : Bouton de réglage du volume "-"
(*) selon source audio sélectionnée : tuner, changeur CD, CD, cassette, téléphone (selon équipement).
NOTA : L’appui simultané sur les touches ("d") et ("f") permet de commander la fonction "mute".
