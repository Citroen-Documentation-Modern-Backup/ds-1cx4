2. Demi-coussinets de paliers de vilebrequin
Figure : b1cp0nkd
Le jeu de fonctionnement des paliers du vilebrequin est obtenu par la création de plusieurs classes de demi-coussinets :
  • 1 classe de demi-coussinets supérieurs (côté carter-cylindres)
  • 5 classes de demi-coussinets inférieurs (côté carter chapeaux de paliers de vilebrequin)
2.1. Demi-coussinets supérieur (rainuré)

2.2. Demi-coussinets inférieur (lisse)
Figure : b1cp0nld
Les classes des coussinets de palier de vilebrequin sont reportées sur le bloc moteur en " f" et sur le vilebrequin (côté distribution) en "g".
"h" Code à barres : Utilisé en usine.
"j" Caractères alphanumériques : Utilisé en "après-vente".
Le premier caractère correspond au palier N° 1, le deuxième au palier N° 2, ainsi de suite.
NOTA : Les paliers de vilebrequin sont repérés de 1 à 5, n°1 côté volant moteur.
Figure : b1cp0nmd
Exemple :
  • Caractères relevés sur le vilebrequin : A7H6D
  • Caractères relevés sur le carter-cylindres : EPTG6
Pour le palier N° 1 (AE), le demi-coussinet inférieur à monter est de classe J.
Pour le palier N° 2 (7P), le demi-coussinet inférieur à monter est de classe K.
NOTA : Procéder de la même manière pour les 3 autres ensembles.

3. Demi-flasque
Figure : b1cp0nnd
Le jeu latéral de vilebrequin se règle par demi-flasques sur le palier N° 2.
Le jeu latéral de vilebrequin doit être compris entre 0,06 et 0,15 mm.
La cote nominale "M" est comprise entre 2,28 mm et 2,33 mm.
NOTA : Il n’y a pas de réparation sur les demi-flasques.
