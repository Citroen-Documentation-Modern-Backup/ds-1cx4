4. Pose de l’articulation élastique arrière

Engager le bras inférieur de suspension ( 1) dans la rainure de l’outil [7].
Monter l’outil [ 10] sur l’articulation élastique arrière (2).

Engager l’outil [ 8] sur l’articulation élastique arrière (2).

ATTENTION : L’articulation élastique arrière ( 2) est montée sur le bras inférieur de suspension (1). Le montage de l’articulation élastique arrière (2) doit s’effectuer avec un effort à l’emmanchement. Lorsque l’articulation élastique arrière (2) se monte librement, procéder au remplacement du bras inférieur de suspension (1).
