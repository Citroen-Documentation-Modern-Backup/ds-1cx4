D4EM3ZP0Opérations après-vente : Essuyage / lavage
DEPUIS OPR 9618
1. Lecture des défauts
Il est possible de lire les défauts suivants à l’aide de l’outil de diagnostic :
  • Défaut commande de l’essuyage avant
  • Défaut de communication sur le fil DATA BARRE avec le capteur de pluie
  • Défaut de communication sur le fil DATA avec le capteur de pluie
  • Défaut de communication avec le capteur de pluie
