C4AG0UP0Dépose - repose : Capot moteur
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Dépose
Figure : c4ap14ld
Désaccoupler le tuyau lave-vitre ( 6).
Dégrafer les stabilisateurs ( 4).
1.1. Capot seul
Desserrer les vis (3).
Déposer les vis (2).
1.2. Capot avec bras d’articulation
Déposer :
  • L’enjoliveur de bas de pare-brise
  • Les vis (5)
Déposer le capot (1) (à l’aide d’un 2ème opérateur).
2. Déshabillage
Figure : c4ap14md
Déposer :
  • Les gicleurs de lave-vitre ( 14)
  • Les clips (12)
  • L’enjoliveur de capot (15)
Déposer :
  • Les cales latérales ( 11)
  • Le joint d’étanchéité (13)
  • Les butées caoutchouc (7)
  • Les agrafes (8)
Relever les languettes ( 10).
Déposer la garniture de capot ( 9).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
ATTENTION : Respecter les jeux et affleurements.
