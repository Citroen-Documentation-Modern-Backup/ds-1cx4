D4EB19P0Généralités : Affichage multifonction (écran couleur)
DEPUIS OPR 8631
1. Préambule
L’affichage multifonction couleur est réalisé par les éléments suivants :
  • Un écran couleur à cristaux liquides au format 16/9 de 7 pouces
  • Un calculateur d’affichage (dans la boîte à gants)
Le calculateur d’affichage est connecté au réseau VAN Confort et assure les fonctions suivantes :
  • Information du conducteur sur les éléments extérieurs au système (date, heure, température extérieure)
  • Information du conducteur sur les éléments internes au système (autodiagnostic, ordinateur de bord)
  • Gestion de l’affichage de l’autoradio
  • Gestion de l’affichage du changeur CD
  • Gestion de l’affichage du radiotéléphone
  • Gestion de l’affichage du système de navigation
ATTENTION : Les fonctions pilotées par les écrans multifonctions de type A, B et C (affichage monochrome), sont pilotées par le calculateur d’affichage, en affichage couleur. Les documents relatifs à l’autoradio sont applicables à l’écran couleur de type D.

3. Description matérielle
3.1. Écran multifonction couleur
L’écran multifonction couleur ne possède pas de logique de calcul, il se comporte comme un périphérique de sortie.
L’écran multifonction couleur reçoit et affiche les données graphiques numériques en provenance du calculateur d’affichage.
Figure : d4ap028c
Caractéristiques de l’écran multifonction couleur :
  • Diagonale : 7 pouces (17,78 cm)
  • Format : 16/9
  • Technologie : Écran à cristaux liquides à matrice active (LCD TFT)
3.2. Calculateur d’affichage
Le calculateur d’affichage est implanté dans la planche de bord (au-dessus de la boîte à gants).
Le calculateur d’affichage permet d’afficher les informations suivantes à l’écran multifonction :
  • Commandes utilisateur (liaison filaire)
  • Données graphiques issues du calculateur de navigation couleur (liaison optique)
  • État de l’autoradio (réseau VAN Confort)
  • État du changeur CD (réseau VAN Confort)
  • Calcul des données graphiques pour l’écran multifonction
  • Envoi des données graphiques à l’écran multifonction (liaison filaire numérique)
Figure : d4ap02bc
3.3. Commande de l’écran multifonction
Figure : c5fp0dgc
La commande de l’écran multifonction est implantée sur la console centrale, à côté du frein de stationnement.
La molette de sélection permet de naviguer dans les menus.
La molette de sélection est une roue codeuse sur 3 bits qui permet d’effectuer une sélection bidirectionnelle.
Le bouton de validation intégré à la molette de sélection ainsi que les boutons "ESC", MENU" et "MODE" sont des interrupteurs qui permettent de fournir différents niveaux de tension aux broches du connecteur.
