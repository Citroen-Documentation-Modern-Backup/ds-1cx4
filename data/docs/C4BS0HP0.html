C4BS0HP0Dépose - repose : Bras d’essuie-vitre arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Outillage préconisé
Figure : e5ap1gkc
[ 1] extracteur de bras d’essuie-vitres FACOM U.14A.
Figure : e5ap28wc
[ 2] cale d’appui.
ØA = 32 mm.
B = 12 mm.
Outil à réaliser à partir d’une rondelle de 2 mm d’épaisseur.
2. Dépose
ATTENTION : Intercaler la cale d’appui [ 2] entre le bras d’essuie-vitre et les griffes de l’outil [1] pour ne pas détériorer le bras d’essuie-vitre lors de l’extraction.
Figure : c5cp050c
Déclipper le cache ( 1) en "a" À l’aide d’un tournevis fin.
Figure : c5cp063c
Déposer l’écrou (2).
Figure : c5cp064c
Insérer la cale d’appui [ 2] sous le bras d’essuie-vitre.
Figure : c5cp065c
Positionner l’outil [ 1] sous la cale d’appui [2].
Extraire le bras d’essuie-vitre ( 3).
3. Repose
Procéder dans l’ordre inverse des opérations de dépose.
