D4EM14P0Opérations après-vente : Gestion de l’adhérence du véhicule
AVEC SYSTEME ESP
1. Développement de roue différent
Le calculateur d’ESP corrige les informations qu’il délivre lorsqu’il identifie une roue ayant un développement différent de 5% par rapport aux autres roues.
Les régulations d’ABS et de REF doivent être totalement opérationnelles jusqu’à une différence de développement de 12% entre les roues.
Pour des différences de développement supérieures à 12% le système passe en mode dégradé.
2. Capteur d’angle de volant de direction
Le calibrage du capteur d’angle de volant de direction est nécessaire dans les cas suivants :
  • Intervention sur le train avant
  • Intervention sur la colonne de direction
  • Changement du capteur d’angle de volant de direction
  • Intervention sur le module de commande sous volant de direction
NOTA : Un calibrage mal effectué engendre un fonctionnement dégradé de l’ ESP.

5. Test actionneurs
5.1. Véhicule équipé de l’ABS
Il est possible d’effectuer les tests actionneurs suivants À l’aide de l’outil de diagnostic :
  • Activation de la pompe de recirculation pendant 10 secondes
  • Électrovanne admission/échappement roue avant gauche
  • Électrovanne admission/échappement roue avant droite
  • Électrovanne admission/échappement roue arrière gauche
  • Électrovanne admission/échappement roue arrière droite
  • Électrovanne de commutation 1
  • Électrovanne de commutation 2
  • Électrovanne de limitation 1
  • Électrovanne de limitation 2
Lors du test actionneur des électrovannes, l’opérateur doit soulever la roue du véhicule et tourner la roue à la main.
Lorsque les électrovannes fonctionnent correctement, il est possible de tourner la roue du véhicule par saccade pendant 5 secondes.
5.2. Véhicule équipé de l’ESP
Les tests actionneurs pour les véhicules équipés de l’ ESP sont identiques aux tests actionneurs pour les véhicules équipés de l’ABS.
6. Télécodage
Lorsqu’un calculateur n’a jamais été télécodé, un code défaut apparaît.
Un calculateur non télécodé est malgré tout fonctionnel, il fonctionne dans ce cas en mode dégradé.
Si une modification du logiciel intervient, il n’est pas nécessaire d’effectuer un nouveau télécodage.
Lors d’un télécodage, les donnés suivantes sont automatiquement modifiées dans le calculateur :
  • Lieu de l’intervention
  • Signature de l’outil de télécodage
  • Nombre de télécodage
6.1. Véhicule équipé de l’ ABS
Il est possible de télécoder les options suivantes À l’aide de l’outil de diagnostic :
  • Loi de fonctionnement
  • Type de pneumatiques
  • Type boîte de vitesses
6.2. Véhicule équipé de l’ESP
Liste des paramètres supplémentaires aux paramètres des véhicules équipés de l’ ABS :
  • Calibrage du capteur d’angle de volant de direction
  • Décalibrage du capteur d’angle de volant de direction
