B3FG5AP0Dépose - repose : Bloc hydraulique ABS
IMPERATIF : Respecter les précautions à prendre avant intervention.
1. Outillage préconisé
Un presse pédale.
2. Dépose
Déposer :
  • Le cache batterie
  • Le cache boîtier calculateurs (BSM)
BSM : (boîtier de servitude moteur).
Déconnecter le câble négatif et le câble positif de la batterie.
Figure : b1bp26ec
Déposer vis (2).
Déconnecter les connecteurs (1).
Déposer :
  • Le bloc calculateurs ( 6)
  • Le faisceau (4)
  • La vis (3)
Écarter les 3 clips "a".
Écarter le BSM ( 5) du bac (7).
Figure : b1hp17tc
Déposer :
  • Les vis (8)
  • Le bac (7)
Placer le presse pédale sur la pédale de frein, afin d’atténuer l’écoulement du liquide de frein lors du désaccouplement des tubes de frein.
Figure : b3gp02gc
Déconnecter le connecteur (9).
Déposer :
  • Les canalisations hydrauliques ( 10) et (11) (prévoir l’écoulement du liquide de frein)
  • Les écrous (12)
  • Le bloc hydraulique (13)
IMPERATIF : Obturer les entrées et sorties du bloc hydraulique pour éviter toute pénétration de corps étranger.
3. Repose
IMPERATIF : Déposer les obturateurs des orifices de raccordement juste avant le montage des canalisations de frein.
NOTA : Le bloc hydraulique est livré rempli de liquide de frein.
Reposer :
  • Le bloc hydraulique (13)
  • Les écrous (12) , Serrer à 0,8 ± 0,1 m.daN
Accoupler :
  • Les canalisations (11), Serrer à 1,3 ± 0,1 m.daN
  • Les canalisations (10), Serrer à 2 ± 0,2 m.daN
Reconnecter le connecteur (9).
Reposer :
  • Le bac ( 7)
  • Les vis (8)
  • Le BSM (5)
  • La vis (3)
  • Le bloc calculateurs (6)
  • La vis (2)
Reconnecter le connecteur (1).
Connecter le câble négatif et le câble positif de la batterie.
Reposer :
  • Le cache boîtier calculateurs (BSM)
  • Le cache batterie
Purger le circuit de freinage (voir opération correspondante).
Effectuer un essai sur route.
Effectuer une lecture des codes défauts.
